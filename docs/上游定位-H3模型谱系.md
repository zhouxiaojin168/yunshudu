## 3. 决定性一条：池子里的「账号」是消费端账号，不是付费 Key

H3 官方文档里三句话锁死了这一点：

1. 「**平台池**：平台侧维护的账号资源。任务由调度系统挑一个余额足够的账号去打官方接口，**账号每天自动签到补分**。」
   → 开放平台 API Key 没有"签到"；**消费端产品（海螺AI App/网页）才有每日免费额度**。
2. 「`ACCOUNT_EXPIRED`：**执行账号登录态过期**，已自动换号重试」+「401/403 -> 账号失效，换号重试」
   → 池内凭据是**登录态**（会话），不是长期 API Key。
3. 「上游一共 6 个工具，统统一口价 **0.002 credit / 次**（真机逐工具**钱包 delta** 实测）」
   → 计量口径是"钱包余额差"，即**账号钱包**，而非平台的计费账单。

## 5. 最终裁决（H3 算力的来源）

```
用户(买 credit)  ->  H3 站(自研 API, OpenAPI v2.13, 四套门面)
                        │
                        └─ 平台池：批量【消费端账号】(每日签到补分 / 登录态会过期)
                                 │
                                 └─ MiniMax 官方接口（H3=Hailuo03 / H3-Max=Hailuo03Max / Hailuo-2.3 / M3 / Speech / Music / Image）
```

- **不是**「从官方开放平台按量买 Key 再转卖」（那是池① 的做法，见 `docs/池②…`/`REPORT37`）。
- **是**「批量消费端账号 + 每天自动签到领免费额度 + 402 换号重试 3 次」→ 这才是"算力看起来无限"的真身。
- 与 `45.207.214.163:3000` 的关系：**算法范式同族（都是"402 换号"的多账号池）**，但池的层级不同（见 `docs/平台池(H3式)-复刻说明.md` §0）；
  「H3 供货给幻镜AI」这条**仍缺直接证据**（需看到幻镜AI 渠道表里指向 `45.207.214.211:8090` 的 base_url），两站当前均 TCP 不可达。
