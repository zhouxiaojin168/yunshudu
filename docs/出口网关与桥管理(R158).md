**「能不能挖到订阅地址？」**：订阅 URL 形如
`https://api.brfcdu.cn/api/v1/client/subscribe?token=<你的token>`

## 二、桥管理（1+2）

新增 `scripts/bridge-manager.js`（配置文件 `state/bridges.json`）：

```bash
node scripts/bridge-manager.js status                          # 每桥：监听 / 上游 / 出口IP·国家
node scripts/bridge-manager.js up [--force]                    # 起全部桥（已在听跳过）
node scripts/bridge-manager.js down [port]
node scripts/bridge-manager.js switch <port> <upstream>        # ★换上游并重启该桥
node scripts/bridge-manager.js add <port> <upstream> [note]
node scripts/bridge-manager.js exit-ip <port>
```
当前实测：
```
17896 LISTEN  上游=http://127.0.0.1:10090      (Dola 本机中转口 → JP 机场)   出口=213.218.254.4 / Japan
17897 LISTEN  上游=socks5://127.0.0.1:18081    (第二出口 → 自建隧道 CN)      出口=114.66.16.225 / China
18082 LISTEN  上游=(自动探测)                   (取CK独立出口)               出口=213.218.254.4 / Japan
```
**开机自启已装**：计划任务 `ysd-bridge-up`（`schtasks /sc onlogon /rl highest`，命令 `"D:\node-v\node.exe" "<repo>\scripts\bridge-manager.js" up`），`schtasks /query /tn ysd-bridge-up` → Ready。

**Dola 三实例已一号一出口**（写 `Dola-0N/proxy_config.json` 后重启 Dola 主程序生效，实测命令行）：
```
Dola-01 → --proxy-server=http://127.0.0.1:17896   (→ JP)
Dola-02 → --proxy-server=http://127.0.0.1:17897   (→ CN)
Dola-03 → --proxy-server=http://127.0.0.1:18082   (→ JP 自动探测)
```

桥日志同步证明：三个实例的 `www.dola.com / ciciai.com / byteintlapi / mssdk` 等流量分别落在各自桥上。备份：`proxy_config.json.bak-r157`（Dola-01）、`.bak-r158`（01/02/03）。

## 三、静态 ISP 接入口（3，待爷爷给凭据）

静态住宅 ISP 拿到后**一条命令**接进来（Dola 侧要求 HTTP 类型）：

```bash
# 新开一个专用桥（推荐端口 17899）
node scripts/bridge-manager.js add 17899 "http://<user>:<pass>@<host>:<port>" "静态ISP(取CK/养号)"
# 或把已有桥换上游
node scripts/bridge-manager.js switch 17898 "http://<user>:<pass>@<host>:<port>"
node scripts/bridge-manager.js exit-ip 17899        # 立刻验证出口是不是 ISP 的 IP
```
再把要用的实例 `proxy_config*.json` 的 `port` 改成 17899（Dola）/ 或 H3 侧 `--proxy http://127.0.0.1:17899`。Dola 原生「取CK静态IP」框也可直接填同一地址（同一份 IP，两处复用）。

## 四、海外 VPS 出口（4，需先买机器）

新增 `scripts/gw-deploy.ps1`（一键在**任意 Windows VPS** 上部署自建出口网关 `ysd-gw-server.js`）：

```powershell
# 只生成远端脚本（拷到 VPS 上执行）
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\gw-deploy.ps1 -GenerateOnly -GatewayPort 38472 -Token gw_xxxx

# 或 WinRM 直连部署
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\gw-deploy.ps1 -RemoteHost 1.2.3.4 -User Administrator -Pass '***' -GatewayPort 38472 -Token gw_xxxx
```
本机接入：
```powershell
$env:GW_REMOTE='<VPS_IP>:38472'; $env:GW_TOKEN='gw_xxxx'; node scripts/ysd-gw-client.js
curl -x socks5h://127.0.0.1:18081 http://ip-api.com/json     # 出口应 = VPS IP
```
选机建议：**日本/新加坡/美国**的小鸡（$3~5/月）即可；国内那台 `114.66.16.225` 到不了 Google，不能承担取CK那一步。
