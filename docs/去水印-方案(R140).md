# 去水印方案（R140）

## 1. 上游每张图其实预渲染了 3 个变体
响应位置：`POST /api/feed/creation/search/my` -> `data.feeds[].metaInfo.imageMetaInfo.mediaInfo`
```
mediaInfo.url                                  = 带「底部大横幅 Hailuo AI x MINIMAX」+ 右下「AI生成」角标
mediaInfo.downloadURL.watermarkURL             = 和上面同一个文件（同一个 object id）
mediaInfo.downloadURL.aiWatermarkURL           = 只有右下「AI生成」角标  ← 默认改用这个
mediaInfo.downloadURL.hailuoWatermarkURL       = 只有右下「Hailuo AI x MINIMAX」小标
```
实测三个 URL 下载后 sha256 互不相同，逐张目视确认。

## 2. 走不通的路（已实测，别再试）
在 `POST /v2/api/multimodal/generate/image` 的 `parameter` 里塞 `aigcWatermark:false` / `watermark:false` /
`watermark:0` / `needWatermark:false`，或顶层塞 `aigcWatermark:false` —— 6 种写法里只有第一种被接受
（HTTP 200 `code=0`），**但成品图照样带全水印**。结论：上游忽略该参数。

## 3. 落地实现
### 3.1 换变体（干掉品牌横幅）
`config/pool-adapter.hailuo-web.json` / `.hailuo-multi.json` / `.hailuo-web-intl.json`：
```json
"query": { "map": { "url_path": [
  "metaInfo.imageMetaInfo.mediaInfo.downloadURL.aiWatermarkURL",
  "metaInfo.imageMetaInfo.mediaInfo.downloadURL.hailuoWatermarkURL",
  "metaInfo.imageMetaInfo.mediaInfo.downloadURL.watermarkURL",
  "metaInfo.imageMetaInfo.mediaInfo.url"
] } }
```
⚠ 必须写在 `query.map.url_path`（代码读的是 `EP.query.map`）。写在 `query.url_path` 不生效。

### 3.2 抹掉右下「AI生成」角标：`scripts/dewatermark.ps1`
- 纯 `System.Drawing`，零依赖；只动右下那一小块，其余像素原样保留。
- 算法：取角标框**左侧等宽竖条** → 以框左边为轴**水平镜像**（衔接处连续、无硬缝）→ 按**竖直 alpha 缓坡**贴回。
- 默认框（像素反推，2048x2048 与 2304x1728 两种尺寸都覆盖）：`X=0.74W  Y=0.855H  Y2=1.0H  Feather=0.15`
- 单独跑：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts\dewatermark.ps1 -In a.jpg -Out b.jpg`

### 3.3 池子自动接上
`scripts/h3-platform-pool.js` 任务成功回调里：下载选中的变体 → 过 `dewatermark.ps1` → 落 `runtime/media/<task>.jpg`
→ `result_url` 指到 `H3P_MEDIA_BASE/media/<task>.jpg`；任一步失败**自动回退上游原 URL**（不会把任务搞挂）。
新增 `GET /media/<file>` 托管。

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `H3P_DEWATERMARK` | `1` | `0` = 只换变体、不抹角标 |
| `H3P_MEDIA_DIR` | `runtime/media` | 成品图目录 |
| `H3P_MEDIA_BASE` | `http://127.0.0.1:<port>/media` | 对外可访问的基址，**必须改成公网可达的**，否则客户端拿不到图 |
| `H3P_BIND` | `127.0.0.1` | 要让成品图对外可访问时设 `0.0.0.0` |

## 4. 效果
端到端实测（本地池 :9940，真号 #46）：`all-in-one-image-pro` 出图 →
`result_url = http://127.0.0.1:9940/media/task_7410f7ca8205.jpg`，
成品图**品牌横幅 + AI生成角标全部消失**，右下镜像区与画面融合自然。
证据：`runtime/evidence/r140-pool-output2.jpg`（成品）、`wm-*.jpg`（三个变体对照）。

## 5. 边界
- 只抹「右下角那一个小方框」，如果某张图角标位置异常（极端长宽比），可能残余；此时把 `H3P_DEWATERMARK=0` 回退成「只去横幅」。
- 镜像是「用左边内容补右边」，画面**右下角本身有重要内容**（人脸、文字）时可能露馅；对角构图/产品图/风景图基本无感。
- 「AI生成」角标是国内的合规标识，抹掉属你自己的取舍，请自行评估用途与合规。
