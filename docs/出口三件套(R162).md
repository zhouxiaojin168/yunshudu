```bash
node scripts/bridge-manager.js add 17899 "http://127.0.0.1:10090" "机场出口(漫剧/生图/H3 通用)"
```

## 2. 「一号一出口」：出口池轮换器（已完成，实测 3 个不同 IP）

`scripts/exit-rotate.js` 直接驱动 mihomo API，把 100 个节点当出口池：

```bash
node scripts/exit-rotate.js list [--region 美国] [--rate 0.5x]   # 按地区/倍率列节点
node scripts/exit-rotate.js current                              # 当前出站节点
node scripts/exit-rotate.js switch "<节点名>"                     # 手动切
node scripts/exit-rotate.js probe --via http://127.0.0.1:17899   # 出口 IP + 落地 + ISP
node scripts/exit-rotate.js rotate --count 5 --region 美国        # 轮换并落库
node scripts/exit-rotate.js restore                              # 恢复原节点
```

实测（自动恢复到原节点）：


**编排「一号一出口」**（每号登录前先切节点 → 单号单跑登录引擎）：

```bash
node scripts/h3-oneexit.js --in state/h3-accounts.in.jsonl --region 美国 --dry   # 只切节点+探针，不开浏览器
node scripts/h3-oneexit.js --in state/h3-accounts.in.jsonl --region 美国         # 真跑（会开浏览器）
```

DRY 实测：


## 3. 静态 ISP：接入 + 验活（脚本就绪，等凭据）

```bash
node scripts/isp-onboard.js add 17901 "http://user:pass@host:port" "静态ISP(养号/取CK)"
node scripts/isp-onboard.js verify 17901
node scripts/isp-onboard.js status
```

验活报告包含：
- **3 连打出口 IP**：三次一致 ⇒ 真静态；不一致 ⇒ 轮换池（不能当静态号用）
- **落地 + ISP/ASN + hosting 标记**，自动判「住宅/宽带」还是「数据中心(IDC)」（IDC 注册 H3 易被风控）
- **可达性**：`hailuoai.video` / `google` / `ipify` 各一个 200

样例（用机场节点当被测对象）：

```
:17900  213.218.254.4  Japan  未知  静态=true  H3=200
```

采购规格（拿到货直接给王炸凭据即可）：
| 项 | 要求 |
|---|---|
| 协议 | `http://user:pass@host:port` 或 `socks5://…`（本工具两者都吃） |
| 类型 | **静态住宅 / 原生 ISP**（非 IDC；VPS 机房 IP 过不了 H3 注册风控） |
| 绑定 | 一号一 IP（可长期固定）|
| 地区 | 优先 日本 / 新加坡 / 美国（H3 海外站 + 漫剧生图都顺）|
| 数量 | 10 个起（号池扩到 50~100 时按 1:1 加）|

## 4. 海外 VPS：一键部署出口网关（两条路都就绪）

### 4.1 Windows VPS（已有脚本，R158）
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\gw-deploy.ps1 -RemoteHost 1.2.3.4 -User Administrator -Pass '***' -GatewayPort 38472 -Token gw_xxxx
```

### 4.2 Linux VPS（本 R162 新增，SSH 一键）
```bash
bash scripts/gw-deploy-linux.sh --host 1.2.3.4 --user root --key ~/.ssh/id_rsa --port 38472 --token gw_xxxx
```
内部步骤：装 node → 传 `ysd-gw-server.js` 到 `/opt/ysd-gw/` → 写 `/etc/systemd/system/ysd-gw.service`（`GW_PORT/GW_HOST/GW_TOKEN/GW_LOG`）→ `enable --now` → ufw/firewalld 放行 → 验活打印接入命令。

### 4.3 本机接入（Windows）
```powershell
$env:GW_REMOTE='1.2.3.4:38472'; $env:GW_TOKEN='gw_xxxx'; node scripts/ysd-gw-client.js
node scripts/isp-onboard.js verify 18081
```
`18081` 起来后即可：`bridge-manager.js add 17902 "socks5://127.0.0.1:18081"` 给 H3 / Dola 用。

> 选择建议：**静态 ISP 优先**（住宅 IP 过风控）；VPS 网关解决「明文 HTTP 代理被 IDC DPI 拦」的运输问题，两者可叠加（VPS 里再挂 ISP 也可以）。
