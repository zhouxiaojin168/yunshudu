# H3（海螺/MiniMax 视频）号池组成结论 · R88 实测版

> 结论一句话：**号池建在海外站 hailuoai.video，账号用「邮箱 / Google」注册；不要用手机号（国内 +86 号源拿不到），也不要用 Facebook（代码里只在「绑定」流程出现）。**

## 1. 两个站其实是同一套客户端
| 证据 | 国内 hailuoai.com | 海外 hailuoai.video |
|---|---|---|
| 公共参数（模块 99273/3340） | `app_id=3001, version_code=22203, biz_id=0, device_platform=web` | **完全相同** |
| 签名算法 | `yy = md5(encodeURIComponent(path)+"_"+body+md5(String(time))+"ooui")` | **完全同一套**（scripts/hailuo-sign.js 两站都是 7/7 code=0） |
| 存储键 | cookie `_token`；localStorage `UNIQUE_USER_ID`/`USER_HARD_WARE_INFO` | **完全相同** |
| Firebase 项目 | `hailuo-ai` / `hailuoai-fd23b`（同一 apiKey） | **完全相同** |
| 代码模块号 | 3340 / 1068 / 4907 / 6653 / 8b4eecab… | **同一批模块号** |

⇒ 技术上下单接口一模一样，**选哪个站是「号源 + 定价」的商业选择**，不是技术选择。

## 3. H3 视频本身：两站价格几乎一样
- 共有视频模型：`23000/23010/23001/23011/23102/23021` = 25 算力；`23200/23204/23217` = 25~80；`23210` = 25~80（唯一 supportFrame）；`23218` = 12~50。
- 768P-6s 一条 = 25 算力 ⇒ 国内 **¥1.75/条**，海外 **$0.25 ≈ ¥1.79/条**（差 ~2%）。
⇒ **成本上两站平等；"能不能规模化"由号源决定，不由价格决定。**

## 4. 为什么必须是「海外站 + 邮箱/Google」
1. 国内站 = +86 手机号强绑定（且需要短信验证码）。公开接码平台（5sim/onlinesim/sms-man/smsbower 实测）**不卖中国大陆号码** ⇒ 批量号源**不可得**。
2. 海外站 = 邮箱/Google 登录，**不需要接码**，Gmail/自有域名邮箱可批量 ⇒ 唯一可规模化的号源。
3. 新人礼海外站约为国内 **1.9 倍**（$1.5 vs $0.8 等值）。
4. 海外站模型多 9 个（含漫剧-复刻要用的全部生图模型）。

## 5. 登录接口的风控现状（实测）
- `POST /v1/api/user/login/sms/send`（含 3 种字段拼法）→ 全部 **HTTP 400 code=2「请求异常，请检查请求参数」**，debugInfo 为空。
- `POST /v1/api/user/login/email`（含 {}、`{"email":...}`、`{"email":...,"code":...}`、`{"mail":...}`）→ 同样全部 400 code=2。
- ⇒ 登录接口带**浏览器侧风控票据**校验（响应里可见 Akamai `ak_bmsc` / `bm_sz` 指纹 cookie，前端还有 `yy_platform` 参数）⇒ **纯脚本登录不可行**，必须浏览器真人登一次（或补票据）。
- 登录后 `_token` 由服务端 Set-Cookie 下发（非 httpOnly），落地形态：`<_token>|<uuid>|<device_id>`。
- 有效工作路径：`hailuo-login.js verify`（只读验号）→ `hailuo-login.js add`（入池 9940）。

## 6. 对「无限算力」的直接影响
- 新人礼是**一次性**的（transactions: ALL=1/GIVE=1），**没有每日签到接口** ⇒ 单账号只能贡献一次额度。
- 所以「无限算力」= 持续向池子**新增账号**：`pool-supply(9950)` 的健康数下限触发补号 → 海外站邮箱/Google 号源 → `add` 入池 → 池子按「最肥优先 + 预占 + 402 换号」对外供算力。
