# H3 号池（海外海螺 hailuoai.video）—— 补号 / 调度 / 算力来源实证

> 2026-10-14 落盘。工具：`scripts/h3-pool.js`、`scripts/h3-pool-daemon.js`、`scripts/h3-video-test.js`、`scripts/install-h3-pool-task.ps1`

## 0. 一句话结论

**海外海螺邮箱号池只产「账号外壳」，不产算力。** 海外站新号 `totalCredits = 0`、无新人礼；
真发视频被业务码 **2400008 Insufficient credits** 拒单。免费算力只存在于**国内站**（新人 80 积分），
但国内站登录强制**绑手机号**（1200044），邮箱路进不去。

## 1. 站点与账号事实

| 项 | 海外站（H3 / MiniMax Hub） | 国内站 |
|---|---|---|
| 域名 | `hailuoai.video` | `hailuoai.com` |
| 邮箱验证码注册 | ✅ 可行（headless） | ❌ 1200044 未绑定手机号 |
| 新人礼 | `new_user_credit.credit = 0` | `new_user_credit.credit = **80**` |

## 2. 注册链路（已跑通，headless，无浏览器）

```
取信箱(mailfarm) → POST /v1/api/user/login/sms/send {phone:"",email,ticket:"",randStr:""}
                → mailfarm 读码（long-poll /v1/mailboxes/{addr}/code?timeout=N）
                → POST /v1/api/user/login/email {email,code}  ⇒ 200 code:0 + JWT
```

签名（EN/CN 一致）：

```

GET 时 body 固定 '{}'；header: token / yy
```

## 3. 补号器 `scripts/h3-pool.js`

```
node scripts/h3-pool.js --n 100 --concurrency 6 --stagger 1500 --retries 3
```

- 并发 worker 池；信箱 `acquire_batch` 批量预取（50/批）
- 指数退避 `base*2^(n-1)+抖动`（上限 30s）；每号最多 `--retries` 次重试
- 验证码 long-poll；验证码慢时**同一信箱再续等 90s**（不浪费号）
- 风控识别（429 / 频繁|限速|too many|rate limit|captcha）→ **全局冷却** 60s
- 失败逐条留档 `<out>.failed.jsonl`；统计落 `runtime/evidence/h3-pool-run-<ts>.json`
- 每号固定自己的 `uuid`+`device_id`（签名一致）；登录后立刻取 equity 存进池记录

实测：

| 场景 | 结果 |
|---|---|
| 本地 3 号（并发 2） | 3/3，16.6s，单号 p50 8.4s |
| 本地 100 号（并发 6 / 步进 1.5s） | **100/100，零失败，154.7s**，p50 6.5s |
| 服务器 200 号（并发 6） | **200/200，零失败，155.4s**，p50 4.5s |

结论：单域名 + 单 IP + 6 并发即可线性扩到 500，无风控、无验证码。

## 4. 调度层 `scripts/h3-pool-daemon.js`

```
node scripts/h3-pool-daemon.js --loop --interval 600 --target 200 \
  --pool runtime/h3-accounts.jsonl --state runtime/h3-pool-state.json
```

- **巡检**：逐号 `/user/info` + `/user/equity` + `/billing/credit`（8 并发）
- **掉号判定**：`401` / `code 1000048`(dead-auth) / `22`(dead-banned) / `2400026|2400040`(dead-nocredit) / 网络失败→`unreachable`（保留观察）
- **自动补号**：存活 < target 时 `spawnSync h3-pool.js --n (target-alive)`，日志 `runtime/evidence/h3-refill-log.jsonl`
- **token 轮转** `--pick`：打分 = 存活 1e9 + 新人期内 1e8 + credits×1e4 − usedCount×100 + 久未使用加权 ⇒ 输出 `token|uuid|device_id` 并累加使用计数（供 pool-supply 直接调用）
- `--status` 报表 / `--prune` 剔死号（自动 .bak） / `--once`（cron 模式）
- **首轮即「巡检+补号」；补过号再复检一轮**，报表准确

## 5. 部署形态（本地 / GitHub / 服务器）

| 位置 | 形态 | 入口 |

| 本地（可选） | `scripts\install-h3-pool-task.ps1 -MailKey mfa-… -Target 200 -IntervalMinutes 30` | 任务 `h3-pool-daemon`（Cron）/ `-Mode Loop` |
| 部署链 | 本地 commit → push（`zhouxiaojin168/yunshudu`）→ 服务器 `yunshudu-deploy` 拉取 → `post-deploy.ps1` 自动注册/重启服务 | `deploy\poke-deploy.ps1 -ExpectSha <sha>` |

> 坑：`poke-deploy` 报 `DEPLOY_TIMEOUT` 但 `last=` 是**完整 SHA** 属正常（全 SHA vs 短 SHA 比较）。
> 坑：生成的 `.ps1`（含中文路径）必须写 **UTF-8 带 BOM**，否则 PS 5.1 按 GBK 读会把路径读乱。

## 6. 真发视频验证 `scripts/h3-video-test.js`

```
node scripts/h3-video-test.js --pool runtime/h3-accounts.jsonl \
  --models "hailuo3.0-t2v:768:4,23218:768:6,hailuo_h3_max_t2v:480:5" --poll 8
```

- 正确 body（`referenceMode`/`projectID` 必须**字符串**，否则 HTTP 400 `bind body failed`）：

```json
{"quantity":1,"parameter":{"modelID":"hailuo3.0-t2v","desc":"...","fileList":[],
 "useOriginPrompt":true,"resolution":"768","duration":4,"aspectRatio":"16:9","referenceMode":"0"},
 "videoExtra":{},"projectID":"0"}
```

实测（新注册号）：

| 模型 | 档位 | 返回 |
|---|---|---|
| `hailuo3.0-t2v` | 768p/4s | 2400008 Insufficient credits |
| `23204` | 768p/6s | 2400008 Insufficient credits |
| `23218` / `23217` / `23021` / `23210` / `hailuo_h3_max_t2v` | 各默认档 | 2400001 Content generation error |
| 前后额度 | — | `totalCredits 0 → 0`、`total_credit 0 → 0`（拒单不扣费） |
