## 第 2 步：域名加进 Cloudflare（10 分钟，含等 NS 生效）

1. Cloudflare 后台 → **Add a site** → 填入域名 → 选 Free plan
2. CF 给你两个 NS（形如 `xxx.ns.cloudflare.com`）→ **回注册商后台改成这两个 NS**
3. 等状态变 **Active**（几分钟到几小时）

然后生成一个 API Token：**My Profile → API Tokens → Create Token → 自定义**，权限给：

| 权限 | 级别 |
|---|---|
| Zone / DNS | Edit |
| Zone / Zone | Read |
| Account / Workers Scripts | Edit |
| Zone / Email Routing Rules | Edit |
| Account / Account Settings | Read |

## 第 3 步：一条命令配完（1 分钟）

~~~bash
# 先看计划（不改任何东西）
node deploy/cloudflare/setup-cloudflare.js --domain yunshudu.xyz \
  --ingest-url https://<隧道域名>/mailfarm/v1/ingest --ingest-key <KEY> --dry-run

# 真跑（token 用环境变量更安全）
set CLOUDFLARE_API_TOKEN=<你的token>          # PowerShell: $env:CLOUDFLARE_API_TOKEN="..."
node deploy/cloudflare/setup-cloudflare.js --domain yunshudu.xyz \
  --ingest-url https://<隧道域名>/mailfarm/v1/ingest --ingest-key <服务器 secrets.txt 里的 MAILFARM_INGEST_KEY>
~~~

脚本会自动做完：开启 Email Routing（CF 自动加 MX）→ 写 `TXT v=spf1 -all` → 上传 Email Worker →
Catch-all 指向 Worker → 回读 MX / catch-all 复核。

然后服务器上把域名加进 `MF_DOMAINS`（`services.json` → deploy，或直接改环境重启 mailfarm）。

**验证**：随便从外部邮箱发一封到 `test@yunshudu.xyz`，然后：
~~~bash
curl "https://<隧道域名>/mailfarm/v1/mailboxes/test%40yunshudu.xyz/code?timeout=60" -H "x-api-key: <MF_API_KEY>"
# 期望 {"address":"test@yunshudu.xyz","code":"...","found":true}
~~~

## ⚠️ 两个稳定性提醒

### 1. 当前隧道是「临时隧道」，URL 会变
现在用的是 cloudflared 免账号快速隧道（`xxx.trycloudflare.com`），**重启就换域名**。
临时用没问题；要长期稳定，建议换 **named tunnel**：
- CF 后台 Zero Trust → Networks → Tunnels → 建一条 named tunnel，拿 tunnel token
- 给它绑一个自定义域名（如 `farm.yunshudu.xyz`）指向 `http://127.0.0.1:8080`
- ingest URL 就固定成 `https://farm.yunshudu.xyz/mailfarm/v1/ingest`

### 2. 25 端口仍然别指望
机房端口白名单没放行 25（实测 25/2525 外网一律 ECONNREFUSED）。
走 CF Email Routing 就**完全不需要** 25；除非你想「MX 直指本机」，那得找 IDC 开工单（国内多半还要备案）。
