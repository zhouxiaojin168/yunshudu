# 号源：接码平台实测与「100% 新号」（R140）

## 1. 结论先说
- **没有任何一家接码平台会承诺「该号从未注册过海螺」**。号源干不干净取决于它背后那张号码池，是概率问题。
- 海螺的免费额度 = **一次性新人礼 80 贝壳**，**只给真新号**，有效期 ~3.8 天。回收号 = 0 额度。
- 所以「无限算力」= **批量抽号 × 抽中真新号 × 80 贝壳**，没抽中就丢弃。这套抽奖逻辑池子已经自动化了。

## 2. d1jiema 实测（当前在用的平台）
API 文档：`https://www.d1jiema.com/api.html`（`code=getPhone / getMsg / send / leftAmount / queryUsed`）

| 项 | 实测值 |
|---|---|
| 单价 | **0.4 元/次取号** |
| 账户余额 | 16.60 元（≈ 41 次取号） |
| 取号参数 | `keyWord=<URL编码关键词>&cardType=[实卡\|虚卡\|全部]&province=可选` |
| 重复号 | **平台自动拉黑重复号码**（自己用过的不会再来） |
| 历史查询 | `code=queryUsed`（最近 24h 100 条，每分钟最多 1 次） |

### 命中率（真新号 = 有 80 贝壳）
| 号源 | 结果 |
|---|---|
| 服务器累计 19 次取号 | **6 个拿到额度**（80/80/80/74/74/68）→ 约 **30% 命中** |
| 本机 R133 三次 + 今天 1 次 | 4/4 **全是 0 额度回收号** |
| 今天 `cardType=实卡` 实测 3 次 | 2 个注册成功但**都是 0 额度**，1 个连短信都没收到 → **实卡过滤不解决干净度** |

→ 结论：**`cardType` 换实卡/虚卡没用**，命中率就是 ~30% 的抽奖。
→ 但 0.4 元抽一次，平均 **1.33 元拿到一个 80 额度的新号** = 13 张图 → **每张图上游成本 ≈ 0.10 元**。

## 3. 「100% 新号」的三条真路
### 路线 A：把抽奖自动化（已实现，零改造）
池子本来就会：抽号 → 注册 → 探钱包 → **0 额度立刻 prune** → 健康数不够再抽（带 5~60 分钟指数退避熔断，防死循环烧钱）。
你只要把 `SUPP_POOL_MIN` 设成目标健康号数，它自己滚。

### 路线 B：换/加接码平台做 A/B（成本 1.2 元/家）
用同一套脚本换 `SUPP_SMS_GET / SUPP_SMS_POLL` 即可，**没有代码改动**。测法：每家抽 3 个号，看有几个 `credits>0`。
> ⚠ 只认**国内 +86** 号源：海螺国内站（hailuoai.com）只走「手机号+短信」，海外站（hailuoai.video）**根本没有手机号/邮箱入口（只有 Google/Apple）**，
> 所以 **5sim / sms-activate / smspva 这类卖海外号的平台对海螺没用**。

### 路线 C：自建号源 = 唯一真正的 100% 新号
1. **猫池 + 白卡/物联卡**：买一批从未注册过海螺的卡，插猫池（8/16/32 口），自建短信接收网关给 `SUPP_SMS_GET/POLL` 当后端。
   号码 100% 新，边际成本 ≈ 0；代价是一次性硬件 + 卡源/实名问题（这块自己评估合规）。
2. **成品号直供**：找号商直接买「已注册 + 80 贝壳」的成品号，导进池子即可（`POST /pool/accounts/bulk` 或 `scripts/push-farm.ps1`）。
   最省事，但单价高、有被封风险。
3. ~~自建邮箱农场（mailfarm）~~ ❌ **行不通**：海螺国内站只认手机号，海外站没有邮箱入口。

## 4. 一句话建议
先别折腾「找干净平台」——**路线 A 已经能跑，成本 0.10 元/张**；
要压到接近 0 只有路线 C，先决定你愿不愿意上猫池。
