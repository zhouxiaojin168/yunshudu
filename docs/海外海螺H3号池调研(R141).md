# 海外海螺 H3 号池 · 全网调研（R141）

> 时间：2026-10-13 | 只读调研，不改任何第三方系统
> 目标：摸清「海外海螺 H3 号池」到底怎么实现（尤其 B 站 / 油管），并对照我方已落地的国内 H3 池

---

## 0. 一句话结论

- **海外站 `hailuoai.video` 没有手机号 / 邮箱登录入口**，只有 **Google / Apple / Facebook（Firebase）** 三家 → 「接码平台注册」这条路在海外站**根本不成立**。
- 海外号池的通用形态 = **邮箱/Google 账号自建农场 → Firebase 注册 → 浏览器抓 Token/Cookie → 导入池 → 一号一代理 → 轮询 + 自动续签**（与 `flow2api` 完全同构）。
- **油管在本机与服务器均不可达**（直连超时 / 文本镜像 fetch failed / Bing 视频垂类 0 条 yt 链接）→ 本报告以 **B 站 + GitHub + Bing 网页** 为证据源。
- 我方国内 H3 池（手机+短信，`hailuoai.com`）已**全自动跑通并上线**，是本次调研的对照基线。

## 1. 海外海螺号池的实现路径（对标 flow2api）

| 环节 | 做法 | 证据 |
|---|---|---|
| 账号来源 | Google 账号农场（自建注册 / 批量购买） | flow2api README「逆向账号池」 |
| 登录方式 | Firebase（Google / Apple / FB） | 海外站登录页仅此三家 |
| 会话凭证 | 定时刷新完整 Google/Flow **Cookie**，验证登录态 | flow2api 特性表「Cookie 自动刷新」 |
| Token 续签 | Token/JWT 有效期管理 + 协议续签队列 | leo_proxy README「协议续签队列」 |
| 额度读取 | 实时查询 VideoFX Credits | flow2api「余额显示」 |
| 调度 | 多 Token 轮询 + 并发控制（负载均衡） | flow2api「负载均衡」 |
| 代理 | HTTP/SOCKS5 一号一代理（住宅 IP） | flow2api + ProxyLane 赞助（195 国住宅代理） |
| 打码 | reCAPTCHA v3 第三方打码（YesCaptcha/CapSolver/2Captcha） | flow2api 前置要求 |
| 导入 | **Cookie ZIP 批量导入** + 浏览器扩展推送新登录态 | leo_proxy / Flow2API-Token-Updater |

> 结论：海外路径**没有接码环节**，核心是「**Cookie/Token 农场 + 代理池**」，不是「手机号池」。

### 7.1 油管上「海外海螺 H3 号池」的真实情况

- **没有**任何教程讲「海螺号池 / 账号农场」——**与 B 站结论一致**，号池是「闷声做」的活。
- 油管的「无限额度」内容绝大多数是 **mod APK / 拉新活动 / 第三方壳站（Magiclight、Lory、runninghub）**，不是号池。
- 唯一贴近的一条：**《Hailuo AI Free: 60 Credits a Second — and No Published Allowance》**（VideoFreeTier，2026-10）——指出**免费账号只能跑 MiniMax H3 这一个模型**，60 credits/秒。→ 与我方「用 H3 免费额度」的定位吻合。
