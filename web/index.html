03接入方式

任何 OpenAI 兼容客户端都能直接用：把 Base URL 换成网关地址、Key 换成你在控制台签发的令牌即可。

curl Node.js Python 环境变量

  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的令牌" \

console.log(await r.json());
from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:3300/v1",

04号池 / 算力池是怎么来的

一个渠道 = 一个号池。这就是"无限算力"的全部秘密：一批额度有限的 key 排队轮询，池子续得上就继续跑。

1
建池：把 N 把 key 塞进同一个渠道

渠道的 key 字段用换行拼接，建渠道时 mode=multi_to_single，否则池子静默失效。

2
取号：轮询 / 随机

multi_key_mode=polling 按顺序切号，random 随机切号；请求级递增，池内负载自然摊平。

3
熔断：只踢坏掉的那一把

status_code_mapping={"402":"401"} + auto_ban=1 —— 上游额度耗尽的 402 被改写成 401（认证失败），于是只封这把 key，轮询自动换下一个号。

4
整池：全灭才下线

池里 key 全部失效才禁用渠道；补进新 key 或上游恢复后自动重新启用。

关键一步：如果不做 402→401 映射，402 会被当成渠道级故障，整池一起挂 —— 很多站"一挂全挂"就死在这。

05本地 / 服务器部署

本仓库自带一键脚本：免 Docker、Windows 直接跑；换 Linux 把 exe 换成对应架构二进制即可。

PowerShell
# 拉代码
git clone https://github.com/zhouxiaojin168/yunshudu.git
cd yunshudu

# 一条命令拉起全套（下载二进制 → 起网关 → 初始化 → 起模拟上游 → 建池 → 计价 → 冒烟）
powershell -ExecutionPolicy Bypass -File .\scripts\start-all.ps1

# 起网页门户（可选）
node .\scripts\serve-web.js
